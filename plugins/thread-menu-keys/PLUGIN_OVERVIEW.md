Adds visible key hints and single-key actions to open Cloudroom thread menus.

- **P** pin/unpin, **U** mark read/unread, **R** rename, **A** archive/unarchive.
- **C** copies the thread ID when the thread-ids plugin supplies that item.
- **S** opens in split when available; **Delete** opens the native confirmation.

Keys activate the menu's existing item and apply to its thread. They do not
operate globally or inside text inputs, submenus, or unrelated dialogs.

This plugin adds no page, CLI command, settings, storage, or bundled skill.
Disable it to remove the hints and keyboard handling. See README.md for the
full key table, compatibility limits, and focused checks.
